# Villacar Autos LLC

Quality Pre-Owned & New Vehicles - Your Trusted Auto Dealer in Albuquerque, NM

## 🚗 About

Villacar Autos LLC is a modern automotive dealership website built with Astro, featuring a responsive design and comprehensive vehicle management system.

## 🚀 Project Structure

```text
/
├── public/
│   ├── favicon.svg
│   ├── manifest.json (PWA)
│   ├── sw.js (Service Worker)
│   └── offline.html
├── src/
│   ├── components/ (18 reusable components)
│   ├── data/ (Vehicle data)
│   ├── layouts/ (Main layout)
│   ├── pages/ (12 pages + API routes)
│   └── styles/ (Global CSS)
└── package.json
```

## ✨ Features

- **Vehicle Inventory** - Browse, search, and filter vehicles
- **Wishlist & Compare** - Save favorites and compare vehicles
- **Financing Calculator** - Calculate monthly payments
- **Test Drive Scheduler** - Book test drives
- **Trade-In Estimator** - Get trade-in values
- **Live Chat** - Customer support widget
- **Blog & FAQ** - Helpful resources
- **PWA Support** - Install as app, offline functionality
- **Admin Dashboard** - Manage inventory (demo mode)

## 🧞 Commands

All commands are run from the root of the project:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally                       |

## 📱 PWA Features

- Offline browsing support
- Install as standalone app
- Background sync for inquiries
- Push notifications ready

## 🔧 Tech Stack

- **Astro** - Static site generator
- **Tailwind CSS** - Utility-first CSS
- **TypeScript** - Type-safe JavaScript
- **LocalStorage** - Client-side data (demo mode)
